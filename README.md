## About

I design, build, and operate backend systems, automation infrastructure, and payment-related tooling. Most of my production work is in **Go**, **PHP**, and **Python**, with occasional **Vue / TypeScript** on the frontend when the project calls for it.

## Expertise

- **Backend & Distributed Systems** — API design, service-oriented architecture, and payment infrastructure
- **Automation & Tooling** — workflow automation, chat bots, CI/CD pipelines, and developer experience improvements
- **Payments & Wallets** — wallet integrations, payment flows, and Taiwan banking code utilities
- **Platform Engineering** — observability, reliability, and long-term maintainable system design
